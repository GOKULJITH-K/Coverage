AXI Interconnect Verification – Functional Coverage

This page provides access to functional coverage dashboards generated for the AXI Interconnect Verification project. Coverage is collected using SystemVerilog covergroups and analyzed with Synopsys URG.

Each test case has an independent coverage database and a dedicated HTML dashboard.
